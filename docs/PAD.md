# PAD — Current Status

Status: **NOT EVALUATED**

The implementation validates PAD artifact metadata, feature dimensions/version, class semantics, trusted path and optional SHA-256. Missing/invalid artifacts fail closed to `UNCERTAIN`/review.

A valid held-out evaluation set is required for APCER, BPCER, ACER, attack-class breakdown, confusion matrices and threshold/ROC analysis.

Required attack classes include printed photo, display/screen, replay/video and other supported attacks where data exists.
